# P8 — the experiments' raw evidence

Invariant 9: *evidence lives in the repo, outside every blast radius.* This directory holds
the **inputs** an analysis cannot be re-run without; the analyses themselves and their
verdicts live in [`experiments/results/`](../../../experiments/results/REPORT.md).

## What is here

| file | what it is | why it is committed rather than re-derivable |
|---|---|---|
| `h3-livekill-ledger-rows.json` | all 492 `usage_ledger` rows from the operator's 2026-08-10 two-GPU kill demo, exported before the next `make test` | **the ledger is a test fixture.** The Postgres contract suite truncates the control plane and `usage_ledger` references it (H-029), so these rows are one `make test` from gone. They are the only record of a run on hardware CI cannot reach |
| `h2-ledger-rows.json` | the H2 suite run's rows, same shape | *(pending — written by `RUNBOOK.md` §2f)* |

## The one that matters

`h3-livekill-ledger-rows.json` is what makes H3's live half adjudicable at all, and it is the
reason Phase 8 did not demand a fresh GPU session (H-067). The recording already existed —
`docs/evidence/p7-dashboard/` has seven stills, `hero.gif`, and the kill timestamp — but a
picture is not a measurement, and the psql cross-check committed with P7 is three columns
that do not state the caller-visible 5xx count, the `failover_error` breakdown, or the probe
cadence. Those are five queries over rows that were still there.

270 of the 492 rows are the vLLM chain; the rest are `make seed`'s mock traffic sharing the
same ledger, and `experiments/h3/livekill.py` counts them separately rather than filtering
them silently.

Re-run the adjudication any time, from a clone, with no hardware:

```bash
uv run python -m experiments.h3.livekill \
  --rows docs/evidence/p8-experiments/h3-livekill-ledger-rows.json
```

`tests/test_experiments_h3.py` does exactly that on every pull request, and also drives the
analysis with a row edited to carry a 503 — because a verdict that has never been seen to say
FALSIFIED is a verdict nobody should believe.

## What is deliberately *not* here

The H1 corpus and its vectors. They are **inputs to a finding rather than evidence of one**,
they are regenerated by a documented command, and they belong beside the code that reads
them: [`experiments/artifacts/`](../../../experiments/artifacts). The curve, the figure and
the per-probe drill-down are in `experiments/results/`.

Cost of everything in this directory: **$0.00**. The kill demo ran on the operator's own
GPUs.
