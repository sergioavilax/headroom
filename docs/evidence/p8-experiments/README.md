# P8 — the experiments' raw evidence

Invariant 9: *evidence lives in the repo, outside every blast radius.* This directory holds
the **inputs** an analysis cannot be re-run without; the analyses themselves and their
verdicts live in [`experiments/results/`](../../../experiments/results/REPORT.md).

## What is here

| file | what it is | why it is committed rather than re-derivable |
|---|---|---|
| `h3-livekill-ledger-rows.json` | all 492 `usage_ledger` rows from the operator's 2026-08-10 two-GPU kill demo, exported before the next `make test` | **the ledger is a test fixture.** The Postgres contract suite truncates the control plane and `usage_ledger` references it (H-029), so these rows are one `make test` from gone. They are the only record of a run on hardware CI cannot reach |
| `h2-ledger-rows.json` | all 462 `usage_ledger` rows from the H2 suite run `21369386…`, same shape and the same reason | same: one `make test` from gone, and it is the $7.54 side of the two-meter cross-check. Written by `RUNBOOK.md` §2f, whose `SELECT` is pinned to the analyzer's `REQUIRED_COLUMNS` (H-072) |
| `h2-backline-summary-gateway.json` | Backline's own `summary.json` for run `21369386…` — the treatment | H2's parity claim is *against Backline's numbers*, and they live in `~/code/backline/data/evals/`, which is one `make test` **in that repo** from gone. 1.2 KB |
| `h2-backline-summary-direct-local.json` | Backline's `summary.json` for run `a309dc57…` — the direct-local reference, the `93.3` | same, and more so: it is the comparator the pre-registration named. Without it the gate adjudication is an assertion |
| `h2-backline-gate-baseline.json` | Backline's committed `evals/results/baseline.json` | the gate's FAIL is only interpretable against the baseline it failed *to*, including the fact that the entry is a self-described composite of three runs |

## The one that matters

`h3-livekill-ledger-rows.json` is what makes H3's live half adjudicable at all, and it is the
reason Phase 8 did not demand a fresh GPU session (H-067). The recording already existed —
`docs/evidence/p7-dashboard/` has seven stills, `hero.gif`, and the kill timestamp — but a
picture is not a measurement, and the psql cross-check committed with P7 is three columns
that do not state the caller-visible 5xx count, the `failover_error` breakdown, or the probe
cadence. Those are five queries over rows that were still there.

270 of the 492 rows are the vLLM chain; the rest are `make seed`'s mock traffic sharing the
same ledger, and `experiments/h3/livekill.py` counts them separately rather than filtering
them silently.

Re-run the adjudication any time, from a clone, with no hardware:

```bash
uv run python -m experiments.h3.livekill \
  --rows docs/evidence/p8-experiments/h3-livekill-ledger-rows.json
```

`tests/test_experiments_h3.py` does exactly that on every pull request, and also drives the
analysis with a row edited to carry a 503 — because a verdict that has never been seen to say
FALSIFIED is a verdict nobody should believe.

## The H2 half, and why three of these files come from another repo

H2's claim is that Backline's suite scores the same through the gateway as it does direct, so
half of its evidence is *Backline's* accounting, not Headroom's. That half was read live from
`~/code/backline/data/evals/` while the analysis was written, which is exactly the arrangement
invariant 9 exists to forbid: Backline's own test suite truncates that tree, and a published
parity claim whose comparator can be deleted by a routine command in a different repository is
not evidence, it is a memory.

The three `h2-backline-*.json` files are 4.9 KB together. With them, both the parity verdict
and the gate adjudication replay from a clone, with no key, no Postgres and no Backline:

```bash
uv run python -m experiments.h2.analyze \
  --rows docs/evidence/p8-experiments/h2-ledger-rows.json \
  --summary docs/evidence/p8-experiments/h2-backline-summary-gateway.json

uv run python -m experiments.h2.adjudicate \
  --treatment docs/evidence/p8-experiments/h2-backline-summary-gateway.json \
  --reference docs/evidence/p8-experiments/h2-backline-summary-direct-local.json \
  --baseline  docs/evidence/p8-experiments/h2-backline-gate-baseline.json
```

`tests/test_experiments_h2.py` runs both on every pull request and asserts the committed
results are the ones these inputs produce.

The per-question detail — T1 agreement across 133 questions, the `contract_terms`
decomposition, the raw check detail for the one gateway-only T2 violation — needs Backline's
`results.jsonl` (200 KB per run), which is **not** copied here. It is named by run id in
`experiments/results/h2_gate_adjudication.json`'s provenance, and its findings are committed
inside that artifact, so the conclusions are in the repo even where the raw rows are not.

## What is deliberately *not* here

The H1 corpus and its vectors. They are **inputs to a finding rather than evidence of one**,
they are regenerated by a documented command, and they belong beside the code that reads
them: [`experiments/artifacts/`](../../../experiments/artifacts). The curve, the figure and
the per-probe drill-down are in `experiments/results/`.

Cost of everything in this directory: **$0.00 to hold, $7.54 to produce.** The kill demo ran
on the operator's own GPUs; the H2 rows are the receipt for the one paid run of the phase.
